# Galeon dimensions (1:1 model)

The **original artistic reconstruction** represents a generic early-17th-century Spanish galleon, not a precise reconstruction of a named vessel.

Master OBJ orientation: positive Y up, -Z forward, X beam.
Native Minecraft ModelPart orientation: negative Y up, 16 model units per metre.

The OBJ/MTL source includes a curved station-loft hull, individual deck planks, three-tier gilded transom, galleries, cannon ports, bronze cannon barrels, raised forecastle, figurehead, 3 masts, layered square sails with billowed mesh, mizzen lateen sail, bowsprit, rigging and ratlines. The Minecraft Java model is a block-oriented, lower-detail version to remain compatible with native entity rendering.

Historical design sources used for a reasonable dimensional envelope: Deutsches Historisches Museum, Galleon; The Mariners' Museum, Galleon; dimensional overview based on 1607 Spanish shipbuilding regulations.

Milestone 1: static render preview. No steering, buoyancy, walkable decks, or cannon interaction yet.
